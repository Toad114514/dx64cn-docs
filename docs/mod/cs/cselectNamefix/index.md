这是一个基于上游 CS 模组汉化的分支，由 toadXtech64 制作，皆在为了能让名字直接显示中文/日文/俄语等语言  
其特性现在已经合并到了现版本的 Character Select 的汉化中，因此此版本分支无限期停更

## 发展
首先我自己在大概 25 年暑假还是什么时候开始，发现角色直接汉化名字会直接导致整个表直接坍塌。后来发现自带的name实际上也是用于区分这个角色对应的独立id，这可不行。我和上善若讨论了很久没什么办法解决  
然后我自己就想到，要不直接再加一个变量用于显示名称汉化不就行了。于是 Namefix 这个版本便诞生了  
此后虽然我一直有在推广，但实际上此特性因为我觉得可能是比较实验性（就算是后面已经没啥bug了），此分支一直独立于官方的角色选择汉化模组，导致名称支持汉化的很少，而且还很少人用  
于是 v1.16.1 CN-rc3 更新将此特性合并了，此后版本都将内置名称汉化功能。于是此分支便永久无限停更
## 特性
 - 极高的向下兼容，支持原版未汉化角色模组和名称汉化支持
 - 少量代码修改，也保证了维护性、简便性以及未来的更新
 - 方便玩家更快认出角色（也许吧）
