CoopDX 初期开发前后出现的一个库，由 Squishy6094 牵头开发。此依赖库提供了完整的、便捷的将马里奥替换成别的模型的 API，并提供扩展功能例如扩展动作集、自定义声线、HP面板纹理等。同时提供一个方便的选择菜单以便玩家快速切换  
现在大部分的角色模组都要求依赖 Character Select。

## 特性
 - 精美且直观的选择界面
 - 完整的全套 API 添加角色支持
 - 可直接使用的模板
 - 自定义程度高（包括声线、生命图标、HP值面板、动作集、模型本体的自定义动画等）
 - 可对人物分门别类
