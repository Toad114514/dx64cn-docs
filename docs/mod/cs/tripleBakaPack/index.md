经典款术力口模组包，初音未来、重音 Teto 和亚北音留，来到蘑菇王国 -- 低多边形世界探索、发现和击败浏览器！

## 可用角色
 - 一个初音未来
 - 一个重音 Teto
 - 一个亚北音留

至于为什么是这三个，以及标题使用 Triple Baka，参考 [BV1NV4y1w7XV](https://www.bilibili.com/video/BV1NV4y1w7XV)

 - P主特制！（（（bushi 三个人都有自己的音色库

 - 特制帽子音乐
